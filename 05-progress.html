P0 · How to read this page, and what to do first

Page 5 is the honest ledger. Each row says what is done, what is only written, and what is waiting on someone else. Read the state column and the evidence column together: a green DONE with thin evidence is a warning, not a celebration.

If you have ten minutes and no context, do these three things in this order.

  1. Fix the theme test suite. It is the smallest change with the largest effect: four lines of package.json restore the publish gate. Page 3, A3.
  2. Change the campaign rules editor email. Until then, nobody but the outgoing engineer can edit campaign rules. Page 2, B2.
  3. Rotate the Admin API token. It expires on schedule, and the rotation is also the moment the successor takes ownership of it. Page 2, B5.

P3 · Decisions needed from Carson

These are commercial or ownership decisions, not engineering ones. Each blocks something concrete.

  1. Vercel plan. A second team member requires the Pro plan. Without it, the account has to be transferred wholesale, which changes who can deploy.
  2. Deploy identity. The app pipeline requires commits authored logan@seadon.co. Either keep that identity, or change the pipeline to accept the successor's address before 16 December.
  3. Ownership split. Which of Lisa and Leo owns storefront content, which owns the Backer Program, and who signs for access. Page 4 cannot schedule sensibly until this is answered.
  4. Theme test suite fix. Adding a package.json and two dev dependencies to the theme repository is a small change with a real effect: it restores the publish gate.
  5. Permanent token timing. The token expires on schedule. Minting it this week removes a live failure from the critical path.
  6. Campaign rules ownership. The rules editor admits one email address, and the storefront reads a pinned GitHub commit. Someone must own that file after handover, and the email gate needs changing first.
  7. Inventory endpoint exposure. The inventory feed answers without proxy authorisation. Decide whether that stays open or is closed before enforcement.
